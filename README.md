# 🌌 Shikha Yadav — Developer Portfolio

> An interactive, modern, and dark-themed developer portfolio built with React, Vite, and Tailwind CSS. Showcases applied computer vision pipelines, generative AI applications, and full-stack software architecture.

---

## ⚡ Tech Stack & Architecture

- **Frontend & UI:** React (Vite), Tailwind CSS, Lucide Icons
- **Computer Vision & AI:** OpenCV, Contour Analysis, Vision AI Models, Geospatial NDVI
- **Languages:** Python, TypeScript, JavaScript, HTML5/CSS3
- **DevOps & Tooling:** Git, GitHub Actions, Vercel / Render

---

## 🚀 Featured Projects Highlighted

1. **[Sketch2UI](https://github.com/shikhayadav-io/sketch2ui)**  
   *Hand-drawn wireframe sketch to UI code generation engine using OpenCV contour extraction and Vision AI models.*

2. **[ViCodathon Talent Platform](https://github.com/shikhayadav-io/vicodathon_the_aarambhies)**  
   *AI-driven automated candidate assessment and technical evaluation system built for hackathons.*

3. **[Student Attendance & Performance System](https://github.com/shikhayadav-io/student_attendance_performance_system)**  
   *Academic analytics, attendance tracking, and performance evaluation dashboard.*

4. **PraanVayu Analytics**  
   *AI-driven micro-climate and afforestation geospatial engine utilizing satellite imagery and NDVI datasets.*

## 🛠️ Local Development Setup

To run this project locally on your machine:

```bash
# Clone the repository
git clone [https://github.com/shikhayadav-io/portfolio-vibe-engine.git](https://github.com/shikhayadav-io/portfolio-vibe-engine.git)

# Navigate to project folder
cd portfolio-vibe-engine

# Install dependencies
npm install

# Start development server
npm run dev
